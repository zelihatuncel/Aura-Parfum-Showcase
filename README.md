# Aura-Parfum-Showcase

Veritabanı modellemesinden kullanıcı arayüzüne kadar uçtan uca tüm mimarisini tasarlayıp geliştirdiğim B2C e-ticaret platformum Aura Parfüm. Bu proje benim için yalnızca şık bir web sitesi tasarlamaktan ibaret değildi; aynı zamanda veri akışı güvenliğini, karmaşık oturum yönetimlerini ve performanslı sorgu yapılarını kurguladığım tam kapsamlı bir sistem mühendisliği pratiği oldu.

Projenin omurgasını oluşturan veritabanı katmanında Microsoft SQL Server tercih ederek ilişkisel veritabanı mimarisini tamamen sıfırdan inşa ettim. Kullanıcılar, ürünler, kategoriler ve sepet yönetimini veri bütünlüğünü sağlayacak şekilde birbirine entegre ettim. Bu sağlam temelin üzerine Node.js ve Express.js ile asenkron çalışan, optimize edilmiş bir RESTful API yapısı kurdum. Geliştirdiğim sistem sadece bir vitrinden ibaret olmadığı için, arka planda stok ve siparişlerin güvenle yönetildiği, yetkilendirme senaryolarının eksiksiz çalıştığı detaylı bir admin panelini de bizzat kodladım.

İşin son kullanıcıya dokunan frontend tarafında ise lüks ve modern bir marka algısı yaratmak amacıyla hazır şablonlardan tamamen uzak durdum. HTML5, CSS3 ve JavaScript kullanarak kullanıcı deneyimini merkeze alan, projeye özgü dinamik bir arayüz tasarladım. Bir e-ticaret platformunun hem görünen yüzünü hem de arka plandaki o karmaşık mutfağını tek başıma ayağa kaldırmak, yazılım geliştirme süreçlerine olan bütüncül yaklaşımımı çok farklı bir seviyeye taşıdı.
